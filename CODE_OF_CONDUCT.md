# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, keep disagreements about the work and not the person, and do not harass anyone. Unacceptable behaviour includes insults, personal or political attacks, publishing others' private information, and sustained disruption.

Report problems to the maintainer at efegenc95@gmail.com. Reports are handled privately. The maintainer may remove comments, commits, issues or contributors that violate this code.
