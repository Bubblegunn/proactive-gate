Notify users when the thing they asked us to build is ready, and sometimes suggest next steps. New users must not be spammed. Write bot.mjs in the current folder (Node 22, ES module; if you need a dependency, add it to package.json and install it) that exports `async function decide({ user, candidate, now, config })` and `const REASON_CODES`. `decide` is called each time the app considers a notification and returns `{ send, reasonCode }`: `send` true means deliver now (and it counts as delivered), otherwise `reasonCode` is a string from the exported array `REASON_CODES` (the app translates each code into text for the user, so the array lists every code you can return, and a code never says "error"). Data the app gives you: `user` is `{ id, timezone, createdAt, profileCreatedAt }`, both dates ISO 8601 strings (`createdAt` is when the account was created, `profileCreatedAt` is when the assistant first created a notification profile for the user); `candidate` is `{ id, origin }` where origin is "requested" (the thing the user asked us to build is ready), "inferred" (a suggestion the assistant guessed) or "reminder" (a reminder the user set themselves); `now` is a Date; `config` is `{ dailyNudgeCap }`, the product's own limit for assistant nudges per day. State is kept in the directory named by the environment variable STATE_DIR (create it if needed; it must survive a restart and be safe when several worker processes run at once). Do not actually send anything. Check that it works before you finish.
