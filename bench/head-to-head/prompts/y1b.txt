Our marketing system must obey the contact-hour and consent rules of every place we message people, and legal wants each refusal to cite its source. Write bot.mjs in the current folder (Node 22, ES module; if you need a dependency, add it to package.json and install it) that exports `function check({ user, message, now })`. `user` is `{ id, country, state, timezone, consents, existingCustomer }`: `country` is an ISO 3166 code, `state` is a US state code or undefined, `timezone` is an IANA name, `consents` is an object of booleans, `existingCustomer` is an optional boolean. `message` is `{ channel, kind }` with channel "sms", "call" or "email" and kind "marketing". `now` is a Date. Legal's table: (1) US (country "US"), channel sms or call: not before 08:00 and not from 21:00 onward in the recipient's local time (47 CFR 64.1200). (2) US recipients in the states FL, OK and MD: the stricter state window applies to sms and call, 08:00 to 20:00 recipient local time. (3) Country GB or a member of the EU/EEA (DE, FR, IE, ES, IT, NL, SE, PL): a marketing email or sms needs `consents.marketing`, except that `existingCustomer` true is enough (Directive 2002/58/EC article 13; UK PECR regulation 22). No time window. (4) South Korea (KR), sms or email: needs `consents.ad`; sms from 21:00 to 08:00 local time also needs `consents.night`; email is exempt from the night rule (Network Act article 50). (5) Any other country, or email to the US: allowed, no sources. Return `{ allowed, holdUntil, reason, sources }`. `allowed` is a boolean. `holdUntil` is null when allowed or when only a missing consent blocks (a Korean sms between 21:00 and 08:00 without `consents.night` is blocked by a missing consent, so its `holdUntil` is null even though the rule mentions a time of day); when a time window blocks, it is the ISO 8601 UTC string of the earliest moment the same message would be allowed under every rule that applies. `reason` is null when allowed, otherwise one plain sentence naming what blocked the message; for a missing or invalid IANA time zone where a local-time rule applies it must contain "time zone". `sources` is an array of the official URLs of the law behind each rule that applied to the message (for a refusal, the rule that refused; for an allowed message with a rule, the rules that were checked), each on the legislator's, regulator's or official-journal's own site; an empty array when no rule applied. Do not actually send anything. Check that it works before you finish.
