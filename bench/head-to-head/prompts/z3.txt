Add a morning briefing push at the time people wake up, with a way to snooze it or switch kinds of notification off. Write bot.mjs in the current folder (Node 22, ES module; if you need a dependency, add it to package.json and install it) that exports `async function deliver({ user, candidate, now, transport, consentStore })` and `async function recordDismissal(userId, type, now)`. `deliver` is called once per briefing attempt and returns `{ push, inApp, reason, resumeAt }`: `push` and `inApp` say which of the two surfaces received it (booleans), `reason` is a short plain sentence when something was withheld (else null), and `resumeAt` is the ISO 8601 UTC string of when it could go out if that is known (else null). To deliver, call `await transport.push(user, candidate)`, which resolves true when the phone accepted the push and false when it did not (for example no device token), and `await transport.inApp(user, candidate)`, which resolves when the in-app item is stored. `await consentStore.get(user.id)` resolves to the consents object of that user (booleans keyed by purpose) and can throw when the store is down. Data the app gives you: `user` is `{ id, timezone, categories, snoozedUntil, platform, notificationsPermitted }`; `categories` is an object of booleans per notification category (for example `briefing`, `tips`) holding what the user chose in notification settings, missing when they were never asked; `snoozedUntil` is an ISO 8601 UTC string or null; `platform` is "ios" or "android"; `notificationsPermitted` is the operating system's current notification permission as a boolean (may be missing). `candidate` is `{ id, type }` with type "briefing" for the morning briefing and other types for other cards. `recordDismissal` is called when a user swipes a card of that type away. Several worker processes run at once on one machine and share the directory named by the environment variable STATE_DIR (create it if needed; state must survive a restart). Do not actually send anything beyond those two transport calls. Check that it works before you finish.
