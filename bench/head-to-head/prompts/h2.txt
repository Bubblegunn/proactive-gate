Our reminder bot texts and emails users, and each user has three caps that count messages on every channel together: at most 3 per calendar day, at most 7 per calendar week, and at most 12 per calendar month, where day, week and month are the user's own local ones (the week runs Monday 00:00 to Sunday 24:00 local, the month is the local calendar month). The bot runs as several worker processes on one machine at the same time, handling the same users; they can share files on disk, but there is no Redis or other server. Write bot.mjs in the current folder (Node 22, ES module; if you need a dependency, add it to package.json and install it) that exports `async function trySend({ user, message, now })`. `user` is `{ id, timezone }` (IANA time zone name), `message` is `{ id, channel }` with channel "sms" or "email", and `now` is a Date. If every cap still has room, record one message against all three caps and return `{ sent: true, holdUntil: null, reason: null }`. Otherwise record nothing and return `{ sent: false, holdUntil, reason }`, where `holdUntil` is the ISO 8601 UTC string of the earliest moment the same call could succeed (the latest reset among the caps that are full, and later days can be full too, so think about when every cap has room again) and `reason` is one plain sentence naming each full cap with the words "daily cap", "weekly cap" or "monthly cap". Never exceed a cap, even when two workers call at the same instant. State must be kept in the directory named by the environment variable STATE_DIR (create it if it does not exist) so that it survives a restart. Do not actually send anything; recording is enough. Check that it works before you finish.
