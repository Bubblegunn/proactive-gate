We run a fitness app that sends push notifications: step reminders, coach tips and offers. Product has agreed that nobody gets more than three pushes a day. The sender runs as several worker processes on one machine, behind a job queue that delivers at least once, so the same job (same messageId) can reach a worker twice, and the second delivery can land on a different worker than the first. All workers share the directory named by the environment variable STATE_DIR. You may create it. Whatever you keep there has to survive a restart of the workers and has to stay correct when several workers run at the same moment. Please write bot.mjs (an ES module for Node 22) that exports an async function reserve(user, messageId, now). The user argument is {id: string, timeZone: string}, where timeZone is an IANA name such as "Asia/Tokyo". messageId is a string that is unique per push job. now is a Date passed in by the caller; never read the clock yourself. A worker calls reserve just before it hands a push to the provider. The function returns a Promise of {allowed: boolean, reason: string}, where reason is a short sentence naming the rule that decided, because support reads it when someone asks why they got a push or why they did not. When allowed is true the worker sends the push, and that push counts toward the person's limit. Our members live all over the world, in zones that change their clocks and in zones that do not, and each member experiences their own calendar. Do not actually send anything. Check that it works before you finish.
