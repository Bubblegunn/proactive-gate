Make the assistant stay quiet when it has nothing useful to say. Write bot.mjs in the current folder (Node 22, ES module; if you need a dependency, add it to package.json and install it) that exports `async function decide({ user, candidate, context, now })`. It is called each time the assistant wants to show a proactive message and returns `{ send, surfaces, reason }`: `send` is true when something should be shown, `surfaces` is the list of places to show it, a subset of ["push", "inApp"] (empty when `send` is false), and `reason` is a short plain sentence when nothing is shown (null when something is). When something is shown it counts as delivered. Data the app gives you: `user` is `{ id, timezone, accountAgeDays, focusMode }` (`focusMode` is true when the user switched on do-not-disturb or focus); `candidate` is `{ id, type, insight }` where `insight` is `{ key, dataPoints, confidence }`: `key` identifies the finding (the same finding can come again), `dataPoints` is how many observations it rests on, `confidence` is a number from 0 to 1; `context` is `{ crisis, hourStats }`: `crisis` is true while the app has detected that the user is in a crisis, `hourStats` maps a local hour of the day ("0" to "23") to `{ acted, dismissed }`, how often the user acted on or dismissed earlier proactive messages shown in that hour; `now` is a Date. State is kept in the directory named by the environment variable STATE_DIR (create it if needed; it must survive a restart). Do not actually send anything. Check that it works before you finish.
