Our reminder bot texts US customers. Add a weekly digest text and keep us out of trouble. Write bot.mjs in the current folder (Node 22, ES module; if you need a dependency, add it to package.json and install it) that exports `async function trySend({ user, message, now })`, `async function handleInbound({ userId, channel, text, now })` and `async function optOut(userId, channel)`. `trySend` is called for every digest text before it goes out and returns `{ sent, reason }`: `sent` true means the text may go now and is recorded as sent; otherwise `reason` is a short plain sentence. `handleInbound` is called for every text message a customer sends us (`channel` is "sms"). `optOut` is called when a customer turns the digest off on the account page. Data the app gives you: `user` is `{ id, timezone }` (IANA zone name); `message` is `{ id, channel, createdAt }` where `id` identifies the digest event (the queue delivers it at least once and a worker can crash and redeliver it), `channel` is "sms", and `createdAt` is the ISO 8601 UTC time the digest was generated; `now` is a Date. Several worker processes run at the same time on one machine and share the directory named by the environment variable STATE_DIR (create it if needed; state must survive a restart). Do not actually send anything. Check that it works before you finish.
